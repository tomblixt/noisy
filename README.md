# Noisy

Better control for the macOS Background Sounds accessibility feature.

macOS can play calming background sounds (rain, ocean, noise and more), but the controls are tucked away in System Settings. Noisy puts them one click away.

## Features

- Pick and play any of the built-in Background Sounds
- Play and pause, with a volume slider
- Sleep timer (5 minutes to 2 hours)
- Run as a normal window or from the menu bar

## Using Noisy from the menu bar

1. Open **Noisy → Settings…** (⌘,).
2. Under **Show Noisy in**, choose **Menu Bar**. The window closes and the Noisy icon appears in the menu bar.
3. Optionally turn off **Show in Dock** to hide the Dock icon.

## Requirements

macOS 26 or later.
